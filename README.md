# adv — Cardputer Knowledge Base

A public, evidence-based knowledge repository about software and projects for the M5Stack Cardputer. It helps users understand available projects, select them for tasks, and learn from verifiable upstream implementations.

See [GOALS.md](GOALS.md) for the project's strategic vision and desired outcomes, and [AGENTS.md](AGENTS.md) for agent/contributor workflow and repository mechanics.

- **Device:** M5Stack Cardputer
- **Local network details:** intentionally omitted from this public repository.
- **Knowledge base:** [`kb/index.md`](kb/index.md)
- **Local operational lessons:** optional ignored `local-lessons/` store; create locally when needed, not published (see [ADR-004](docs/adr/ADR-004-keep-operational-lessons-in-ignored-project-local-store.md))
- **Private source materials:** `sources/` (local-only; excluded from Git)

Publish synthesized notes with citations and source attribution. Reviewed, bounded research captures may also be published under `kb/raw/` or `kb/research/` after privacy, secret, relevance, provenance, and rights review; they remain evidence, not canonical conclusions. Never publish source clones, books/PDFs, binaries, credentials, private captures, or bulky source originals; keep them in ignored `sources/`. QMD indexing does not authorize publication. The local lessons directory is absent from clean clones by design.

All project changes are governed by GitHub Issues and delivered through reviewed pull requests. Read [GOALS.md](GOALS.md) for project outcomes and [AGENTS.md](AGENTS.md) for agent workflow; use ADRs for durable architectural or publication-boundary decisions.
