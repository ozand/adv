# Cardulator

## Overview

The upstream README describes Cardulator as a scientific calculator and REPL scripting environment. It lists features including unit conversion, formula tools, scripting, and plotting.

## Key facts

- The README describes builds for M5Stack Cardputer ADV and LilyGO T-Deck Pro; this is an upstream statement, not independent device/build verification.
- The README lists PlatformIO build/test commands. They were not run for this knowledge entry.
- No claim is made here about installed firmware, measured performance, or successful operation on a physical Cardputer.

- Launcher catalog listing FID: `9e6b154b57487dea11bdbf2e8aba81da`.
