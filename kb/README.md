# Knowledge Base

Start at `index.md`. The Issue #35 bounded research handoff is linked there; it summarizes project-reported interface examples and does not measure adoption. `raw/` and `research/` contain reviewed, bounded evidence captures; `wiki/` contains synthesized canonical knowledge. Original source material remains local-only under ignored `../sources/`.

Canonical notes live under `wiki/` (entities, concepts, and reports). Each note should cite the upstream evidence it synthesizes; where claims depend on repository content, include an exact revision and record known license limits. Bounded captures under `raw/` or `research/` may be tracked only after privacy, secret, relevance, provenance, and rights review; they remain evidence, not canonical conclusions. Do not copy whole repositories/books, source originals, or unreviewed passages. QMD indexing does not authorize publication.
